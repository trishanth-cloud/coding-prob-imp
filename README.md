# coding-prob-imp

Java coding problems.

## Run a program

After the Codespace is created or rebuilt, create a Java file with a `main` method. For example, save it as `Main.java`, then run:

```sh
javac Main.java
java Main
```

The Codespace installs JDK 21 and the VS Code Java extension pack. Java files are incrementally compiled automatically as you edit them. You can also use the editor's Run and Debug actions for Java files.
